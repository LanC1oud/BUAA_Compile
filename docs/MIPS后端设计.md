# MIPS 后端设计

编译流程为 `源程序 → AST 与语义信息 → IrModule → MipsModule → mips.txt`。
默认目标为 MIPS，`Compiler --stage llvm` 保留原 LLVM 输出能力。后端不修改 IR，生成 MIPS 时同时输出 `llvm_ir.txt`。

## 模块划分

`MipsGenerator` 遍历 `IrModule` 的全局对象、函数、基本块和指令，进行数据布局、栈帧分配和指令选择。
`MipsModule` 分开保存数据段和文本段；`MipsPrinter` 输出可由 MARS 汇编的文本。
`MipsPass` 提供目标代码优化接口，与已有 `IrPass` 分开执行。
`MipsFunctionPlan` 分析块内末次使用、跨块结果和可融合比较；`MipsLocalRegisters` 管理块内 `$t3～$t8` 及按需写回。
各轮改动、代码入口和实测结果统一记录在 [优化日志](优化日志.md)。

`Controller` 在语义检查通过后生成 IR，再根据目标阶段输出 LLVM 或 MIPS。
CLI 编译前清理旧 MIPS、IR、错误文件和配置的优化前 IR，防止失败后保留上次成功产物。
图形界面的 `Pipeline` 提供 MIPS 阶段结果，批量编译按所选阶段执行并清理旧阶段产物。

## 数据布局

| 对象 | 大小与位置 |
| --- | --- |
| 全局变量、全局数组、提升后的局部 static | `.data`，按初始化常量输出 |
| 字符串常量 | `.byte` 序列，保留末尾零、换行和特殊字符 |
| `int`、指针 | 4 字节，按 4 字节对齐 |
| `char`、`i1` 对象 | 1 字节 |
| 数组 | 元素连续排列，遵循元素类型的对齐要求 |
| 形参与 IR 结果的回退槽 | 每槽 4 字节；跨块结果独立，块内生命周期不重叠的结果复用；可重算值不分配 |
| `alloca` 结果 | 固定栈帧内的对象地址，使用时重新计算 |

全零数组使用 `.space`，非零数组按 16 个元素分行输出 `.word` 或 `.byte`。
标签按模块内顺序生成，使用独立前缀区分数据、函数、基本块和后端辅助分支，避免源程序标识符碰撞。

## 栈帧与调用约定

入口标签 `main` 对齐 `$sp` 到 8 字节，调用用户主函数，最后用 syscall 10 结束程序。
用户主函数的返回值不映射为宿主进程退出码；MIPS 回归以程序输出和仿真异常为准。

每个函数入口一次性减小 `$sp`，整个函数执行期间保持不变。栈帧按 8 字节对齐，从低地址到高地址排列如下：

| 相对当前 `$sp` 的区域 | 内容 |
| --- | --- |
| 从偏移 0 开始的调用传参区 | 本函数所有调用中超过四个参数的最大空间 |
| 形参值槽 | 入口立即保存参数，嵌套调用不会覆盖原值 |
| 局部对象 | 按对象类型对齐，真实对象不与临时值槽重叠 |
| 跨块结果槽 | 保守分配独立位置，在离开定义块前保存 |
| 块内回退槽 | 按定义到末次使用区间复用，不同块共用同一区域 |
| 返回地址槽 | 调用普通函数时保存入口 `$ra`；叶子函数不分配 |
| 尾部填充 | 使栈帧大小为 8 的倍数 |

前四个实参从左到右装入 `$a0～$a3`，第 5 个起写到调用方 `$sp + 4*(序号-5)`。
设被调用方栈帧大小为 F，则它从自己的 `$sp + F + 4*(序号-5)` 读取额外参数。
返回值放 `$v0`。所有返回路径汇合到同一尾声，恢复 `$ra` 与 `$sp` 后执行 `jr $ra`。
数组参数传递指针；递归时每层栈帧独立。`char` 参数与返回值始终按无符号 8 位值处理。

后端使用 `$t0～$t2` 计算，`$t3～$t8` 保存块内结果，`$t9` 处理超出 16 位范围的偏移。
寄存器不足时按需写回；调用前只保存调用后仍使用或跨块使用的结果。调用方不依赖 `$t`、`$a`、HI/LO 在调用后保留。
不分配 `$s` 寄存器，不修改 `$fp`，不占用 `$at`、`$k0`、`$k1`。

## 指令选择

| IR | MIPS 处理 |
| --- | --- |
| `ALLOCA` | 在固定栈帧分配对象，使用时生成 `$sp + 偏移` |
| `LOAD/STORE` | 字对象 `lw/sw`，字节对象 `lbu/sb` |
| `GEP` | 按所索引类型的大小计算地址，整数元素乘 4，字符元素乘 1 |
| `ADD/SUB` | `addu/subu`，避免触发有符号溢出异常 |
| `MUL` | `mult` 后读取 LO，保留低 32 位 |
| `SDIV/SREM` | 有符号 `div` 后读取 LO/HI |
| `UDIV/UREM` | 无符号 `divu` 后读取 LO/HI |
| `ICMP` | `slt/sltu`、`xor` 等组合生成 0 或 1 |
| `ZEXT/TRUNC` | 读取已规范化值，按目标位宽截断 |
| `BR` | 直接跳转，或短距离条件分支配合绝对跳转 |
| `CALL` | 按调用约定放置参数，普通函数 `jal`，内建 I/O 使用 syscall |
| `RET` | 设置返回值并跳到共同尾声 |
| `UNREACHABLE` | `break 0`，意外执行时由仿真器报告异常 |

需要运行时计算的 `i8` 运算结果执行 `andi ...,255`，保证 **每一步** char 运算按模 256 回绕，零扩展时保持 0～255。
有符号窄整数运算、比较先按 IR 位宽符号扩展；正常前端的 char 除法和比较使用无符号指令。
大立即数通过 `li` 装入，大栈偏移通过 `$t9` 合成完整地址，避免依赖越界的 16 位立即数。
条件分支只跨越一个绝对跳转，因此大函数也不会超出条件分支范围。

每个跳转后放置 `nop`，能同时在延迟槽开、关两种设置下执行；课程提交按说明关闭延迟槽。
生成代码只使用基础指令、伪指令和数据伪操作，不定义宏。

## 输入输出

| 接口 | syscall |
| --- | --- |
| `get_int` | 5 |
| `get_char` | 12 |
| `get_string` | 8，`$a0` 为缓冲区，`$a1` 为容量 |
| `put_int` | 1 |
| `put_char` | 11 |
| `put_string` | 4 |

使用课程修改版 `mars-2026-BUAA.jar` 的 I/O 语义。`get_string` 的容量 0、1、长行截断、CRLF、连续读取均在课程版仿真器中验证，直接调用 syscall 8。
前端已将 `printf` 拆成 `put_*`，并保持先求值全部实参再输出的语义。

## 优化接口

优化默认开启；`--optimize` 打开后端指令选择优化、已有 IR Pass 列表和 MIPS Pass 列表，`--no-optimize` 关闭。
MIPS Pass 删除跳到下一标签的 `j/nop`，IR Pass 列表默认为空。
`--ir-before 路径` 输出优化前 IR，`llvm_ir.txt` 保存 IR Pass 执行并校验后的 IR。
后续可增加跨块访存消除、活跃变量分析和全局寄存器分配。
当前不生成 PHI；引入 mem2reg 前需要增加 PHI 表示、校验和消除。

## 初步后端优化

本轮保留原始 IR 和调用约定，优化限定在后端，关闭优化时仍使用原生成路径。
运行时临时值继续保留独立栈槽，避免依赖跨块寄存器分配。

| 优化 | 实现与约束 |
| --- | --- |
| 常量重算 | `MipsConstants` 计算纯整数运算、比较和转换的常量结果，使用处直接装入；按每一步 IR 位宽截断，不传播可变内存 |
| 常量条件 | 条件已知时直接选择目标块；保留原 IR，不删除有副作用的调用 |
| 栈地址折叠 | 固定局部对象和全常量 GEP 使用 `$sp + 偏移` 直接访存；无需生成并保存中间指针 |
| GEP 常量偏移 | 合并常量下标的字节偏移，跳过数组首个零下标的乘法 |
| 块内寄存器复用 | 记录寄存器持有的不可变 IR 值，后续使用可通过 `move` 代替 `lw`；目标寄存器被覆盖时失效，跨块、`jal`、syscall 时清空 |
| 小立即数 | 加减常量使用 `addiu`，仅在有符号 16 位范围内选择 |
| 常量乘法 | 乘 0、-1、2 的幂改为常量、取负或移位，保留低位回绕语义 |
| 常量除法与余数 | 无符号除以 2 的幂用逻辑右移，取余用掩码；有符号除法先对负数加偏置再算术右移，保持向零截断 |
| 无用结果 | 不为没有使用者的结果生成栈写入；有副作用的调用仍执行 |
| 叶子函数 | 仅调用 syscall 或没有调用的函数不保存、恢复 `$ra`；调用普通函数时保留原规则 |

寄存器复用只复用 IR 值，不将某个内存地址的上一次读取结果当作下一次读取。
因此数组经形参修改、局部变量重赋值、函数调用等不会错误复用旧内存内容。
有符号 `x / 2^k` 使用 `(x + ((x >> 31) & (2^k - 1))) >> k`；负除数再取负。
余数使用原被除数减去对应商乘以除数。针对 INT_MIN、大掩码、正负除数和窄整数单独验证。

## 初步优化验证结果

2026-11-23 使用相同课程版 MARS、关闭延迟槽的统计结果如下。加权周期是课程定义的指令开销指标，不是宿主机实际耗时。

| 相同的原有 54 个用例 | 备份版默认设置 | 备份版开启旧优化 | 当前默认优化 |
| --- | ---: | ---: | ---: |
| 加权周期合计 | 67948 | 67723 | 45732.5 |
| 执行指令数 | 43520 | 43370 | 30220 |
| 访存指令数 | 23023 | 23023 | 14990 |
| 除法指令数 | 10 | 10 | 0 |

相对备份版默认设置，加权周期下降 32.69%；相对备份版已开启的旧跳转优化，下降 32.47%。
完整的 62 个用例（包含新增 8 个专项测试）中，加权周期由 242758 降至 143912，下降 40.72%。这是这批用例的合计数据，实际收益取决于程序结构。

- 62/62 个用例，优化与延迟槽开关四种组合，共 248 次运行全部通过。
- LLVM 12 回归 39/39 通过；后端不修改输入 IR，IR 前后快照一致。
- 直接 IR 模型额外验证无符号 32 位除法和取余、有符号窄整数除法、比较，以及重复使用同一后端实例。
- 新增专项覆盖正负 2 的幂除数、INT_MIN、随机负数、大立即数、乘法回绕、数组别名与调用后的寄存器失效。
- 原有 54 个用例关闭优化后的统计与备份版逐项一致；课程综合样例的未优化汇编也与备份版逐字节一致。
- 默认编译结果与显式 `--optimize` 一致，提交 ZIP 解包后通过 Java 17 编译及课程综合样例。
- 优化前 170 个文件已恢复校验，备份代码能够独立编译；原地回滚和连续回滚均已在隔离副本验证。
