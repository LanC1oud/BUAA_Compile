# 六阶段分支说明

`Optimize` 为最终优化版本，默认分支由仓库所有者自行设置。前五个分支仅包含对应压缩包中的 Java 源码与 config.json，统一放在 src/ 下；最终项目文档、UI、运行库和测试工具仅保留在 Optimize。

Git 分支名不允许空格，因此 LLVM IR 阶段使用 `LLVM-IR`。

| 分支 | 来源压缩包 | src 文件数 | 根目录内容 |
| --- | --- | ---: | --- |
| Lexer | Lexer.zip | 17 | 仅 src |
| Parser | Parser (2).zip | 64 | 仅 src |
| Semantic | Semantic.zip | 76 | 仅 src |
| LLVM-IR | llvmir.zip | 91 | 仅 src |
| MIPS | MIPS.zip | 96 | 仅 src |
| Optimize | Optimize.zip | 117 | src、docs、ui、runtime、tests、tools 等最终项目文件 |

六个阶段均通过 Java 17（javac --release 17）编译检查。源码保持压缩包中的字节内容，不为整理分支修改历史阶段的代码。Parser 和 Semantic 压缩包中的旧 docs 不进入历史分支。

构建输出、IDE 配置、回滚备份和阶段压缩包不上传。本次仅创建并推送六个阶段分支，不修改 GitHub 默认分支，也不删除原有 main/optimize 分支；后续由仓库所有者自行管理。
